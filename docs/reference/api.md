# API契約

APIの基点はCloudFormationの `ApiEndpoint` 出力です。ローカルデモは `http://127.0.0.1:4310` を使います。
管理APIではCognitoが発行したIDトークンを `Authorization` ヘッダーへそのまま設定します。ローカルデモの一時トークンは実AWSでは使えません。

## 作成

`POST /urls` にJSONオブジェクトを送ります。本文はUTF-8で最大8KB。API GatewayのBase64本文も扱います。
未知のフィールドは400です。

| フィールド | 条件 |
| --- | --- |
| url | 必須。HTTP(S)、最大2048文字。認証情報付きURL、制御文字、空白、不正なポートを拒否 |
| title | 任意。改行を含まない120文字以内。前後の空白を除く |
| custom_alias | 任意。英数字1〜20文字。大文字・小文字を区別。予約語は大小文字を問わず拒否 |
| expires_at | 任意。未来のUnix秒、最大253402300799。nullまたは省略なら期限なし |

日本語ホスト名はIDNA、パス・クエリ・フラグメントはUTF-8のパーセント符号化へ正規化して保存します。
既存のパーセント符号化を二重符号化しません。IPv4/IPv6リテラルは公開アドレスのみを受理します。
ホスト名のDNS解決は行わないため、私設IPへ解決される名前や悪意のあるページを検出できるという意味ではありません。

予約語: `urls`、`app`、`health`、`docs`、`api`、`robots`、`favicon`、`admin`。
ランダムIDは7文字です。条件付き書込で衝突を検出し、最大5回の候補作成を試みます。指定IDの衝突は409、候補を確保できない場合は503です。
停止済み・期限切れのIDも使用済みとして扱います。

201の本文は `short_id`、`original_url`、`title`、`created_at`、`click_count`、`is_active`、`version` を含みます。
期限がある場合は `expires_at`、公開基点が設定されている場合は `short_url` も含みます。

## 一覧と詳細

`GET /urls` は `items`、`count`、`next_cursor` を返します。停止済み・期限切れも管理対象です。
`limit` は評価するレコード数で、標準50、上限200。0・負数・整数でない値は400。200を超える整数は200に制限します。
`next_cursor` がある限り、次回の `cursor` にそのまま渡してください。`count` はそのページの件数です。
Scanに基づくため全体の並び順や、更新中の全件を一時点で読むことは保証しません。画面の検索・集計は読込済み範囲だけです。

`GET /urls/{short_id}` は停止済みを含むレコードを返します。存在しなければ404です。

## 編集と停止

`PATCH /urls/{short_id}` には取得時の `version` と、`url`、`title`、`expires_at`、`is_active` のうち変更する項目を渡します。
`version` は1〜9007199254740991の整数です。古いversion、または対象が存在しない場合は409。再取得して差分を確認してください。
期限を解除する場合は `expires_at: null`。空の更新、未知の項目、不正な型は400です。

`DELETE /urls/{short_id}` は公開を停止します。物理削除ではありません。短縮ID、元URL、タイトル、統計は残ります。
一般利用者向けの個人データ削除機能や、改ざんできない監査ログとして扱わないでください。

## 転送

`GET /{short_id}` は条件付き更新で公開状態・期限を検査し、カウンターを増やした時点の転送先を返します。
状態確認と更新を別の処理にしないことで、途中で停止されたリンクを無条件に転送する競合を避けます。
更新の後に管理者が停止した、既に処理中のリクエストを取り消す保証はありません。

正常時は302と `Cache-Control: no-store`。停止済み・不存在は404、期限切れは410です。
`HEAD` は転送先と状態を確認しますがカウントを増やさず、エラー時も本文は空です。
カウンター更新に失敗した場合は503とし、成功した転送として誤って返しません。

## エラーと保存しない情報

| HTTP | 意味 |
| --- | --- |
| 400 | 入力の形式・型・範囲・ID・cursorが不正 |
| 401 | 管理操作に必要なログインがない、または認証期限切れ |
| 404 | リンクが存在しない、または公開停止 |
| 409 | ID使用済み、編集の競合、処理中に状態変更 |
| 410 | 有効期限切れ、利用できない保存済み転送先 |
| 429 | API Gateway側のスロットリング |
| 503 | 保存先へ接続できない、ID候補を確保できない |

アプリのJSONエラー本文は `{"error":"説明"}` です。API Gatewayが認証段階で拒否する場合はGatewayの形式になります。
DB例外の詳細、元URL、クエリ文字列、認証トークンをアプリのログへ出しません。
