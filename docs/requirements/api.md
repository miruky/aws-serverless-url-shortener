# リンク管理と公開転送の要件

JSONはオブジェクトだけを受理し、HTTP(S)のリンクだけを扱う。短縮IDの衝突は上書きしない。期限と停止を反映する。管理操作は認証を要し、公開リダイレクトは認証不要とする。カウントは人の人数ではなく処理したアクセス数として説明する。

管理画面から作成・コピー・検索・期限設定・編集・停止・再開ができる。スマホでも横にはみ出さず、キーボードと支援技術で操作できる構造にする。
通信失敗では自然な日本語を示し、再試行できる状態へ戻す。画面のトークンを永続保存しない。

管理画面はリンクの一覧を主領域とし、検索・状態・転送先・期限・アクセス数を比較しやすくする。
作成フォームはPCで補助領域に置き、スマホは一覧を先に表示してフォームと往復できるようにする。
集計は読み込み済みの範囲であることを説明し、宣伝用の見出しや未実装の操作を管理画面へ混ぜない。
