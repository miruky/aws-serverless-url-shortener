# 一覧を中心にしたリンク管理画面

## 問題と範囲

大きな見出し・装飾・集計欄が先に現れ、日々操作するリンク一覧が画面下へ押し出されていた。
PCでは一覧を左の主領域、作成フォームを右の補助領域にする。スマホは一覧を先に表示し、作成フォームへ直接移動できるようにする。
API、認証、保存形式、公開停止の確認、検索・集計対象は変更しない。

## 受入条件

- 説明用のヒーローを置かず、初期画面から検索・状態選択・リンクの操作が見える。
- タイトル・短縮URL・転送先、状態・期限、アクセス数を揃えて比較できる。
- 作成・コピー・編集・停止・再開・検索・継続読込を維持する。
- 390pxのスマホ幅で横にはみ出さず、フォームと一覧を往復できる。キーボードのフォーカスが見える。
- 初期空状態、実データを表示した一覧、検索0件、通信エラー、編集画面を確認する。
- 外部フォント、外部画像、装飾用の架空データ、未実装のナビゲーションを追加しない。

## 参照

[Dubのリンク編集画面](https://dub.co/changelog/link-pages)の機能ごとの配置と、[LinearのUI整理](https://linear.app/changelog/2026-03-12-ui-refresh)の落ち着いた階層を参考にする。
ロゴ・画像・ソースの転載は行わない。画面は独自に実装する。

## 検証方針

今回は表示構造の変更であり、見た目に対する人工的なRedを作らない。
既存の実際の回帰ケースCHG-WEB-STAGE-PATHSを現在のAPIスコープで再実行し、資源パスの契約を確認する。
見た目と操作はPlaywrightの既存操作検査、画面幅・アクセシビリティ検査、PC・スマホの目視で別に確認する。
回帰ケースのGreenだけでデザイン品質を証明したとは扱わない。
