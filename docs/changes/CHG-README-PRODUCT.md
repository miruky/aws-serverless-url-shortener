# READMEの読者と構成

READMEを製品の利用者・開発者向けの入口とする。概要、実装済み機能、構成、導入、API、開発コマンド、ライセンスを掲載する。
会話への返答、作業報告、検証状況、未実装・未実施事項の列挙は掲載しない。
ローカルデータの保存期間、認証方式、検索の対象範囲など、利用に必要な仕様は維持する。

文書一覧も利用・運用・開発・設計から参照できる構成とする。
コード・設定値・API・依存関係は変更しない。既存実装との照合、リンク検査、文書の変更伝播で確認する。
