# 改善台帳

対象: miruky/aws-serverless-url-shortener。開始時点: d40bea0e657cb46d85323ecb9655093bc3cb2a16。
既存92テスト・Ruff・mypyはローカルで成功した。ただし、テストが通っていても管理APIの匿名公開などの不足があった。

## 今回の作業範囲

1. 利用者に提供する挙動と、開発・検証・運用の文書を整理する。
2. 個人開発ワークスペースの文書依存グラフを移植し、Pythonの回帰テスト、CI、Gitフックへ接続する。
3. 入力検査、ID衝突、期限・停止、一覧ページング、認証、パッケージングを改善する。
4. AWS認証情報なしでサービスを動かせるローカル開発環境と管理画面を整える。
5. 実装済み・実測済み・今後の候補を分け、READMEの過大な完成表現を改める。

公開、GitHubへの送信、実AWSへの配置はこのローカル作業の完了証拠に含めない。
製品の想定はまず単一の管理者・チームが所有するリンク管理。一般ユーザー登録型SaaSは未決定。
